
Tôi đã thực hiện các bước kiểm tra và chạy thử ứng dụng theo yêu cầu của bạn. Dưới đây là tóm tắt kết quả:

### 1. Khởi chạy ứng dụng
Ứng dụng đã được khởi chạy thành công bằng lệnh:
`doppler run -- npm run start:dev`
Cổng dịch vụ: `30001`
Prefix: `code-payment-service`

### 2. Kết quả Test API (với Token Google)

Dưới đây là kết quả thực hiện các API chính:

| Chức năng | Phương thức | Endpoint | Kết quả |
| :--- | :--- | :--- | :--- |
| **Tạo gói (Plans)** | `POST` | `/plans` | Thành công. Đã tạo gói "VIP 3 Months" (ID: `58ea4ed0-...`) |
| **Lấy tất cả gói** | `GET` | `/plans` | Thành công. Trả về danh sách các gói hiện có. |
| **Chi tiết gói** | `GET` | `/plans/{id}` | Thành công. Trả về thông tin chi tiết gói vừa tạo. |
| **Xóa gói** | `DELETE` | `/plans/{id}` | Thành công. Đã xóa thử nghiệm một gói cũ. |
| **Mua Subscription** | `POST` | `/subscriptions/purchase` | Thành công. Trả về `payment_url` cho cả VNPay và Sepay. |
| **Lịch sử giao dịch** | `GET` | `/subscriptions/history` | Thành công. Hiển thị các giao dịch ở trạng thái `pending`. |
| **Kích hoạt thủ công** | `POST` | `/subscriptions/manual-activate/{id}` | Thành công. Đã kích hoạt giao dịch Sepay thành công. |
| **Thông tin của tôi** | `GET` | `/subscriptions/me` | Thành công. Sau khi kích hoạt, trạng thái là `active` (còn 92 ngày). |
