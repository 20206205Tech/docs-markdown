


Tôi đã chuyển đổi trường `status` của đối tượng `Share` sang dạng `enum` để đảm bảo tính nhất quán với cách xử lý trạng thái trong dự án `code-payment-service`.

### Các thay đổi đã thực hiện:

1.  **Tạo Enum mới:**
    *   Tạo file `src/modules/chat/domain/value-objects/share-status.enum.ts` định nghĩa các trạng thái:
        *   `PENDING`: Đang chờ xử lý (ví dụ: đang tạo file export).
        *   `COMPLETED`: Đã hoàn thành và có sẵn file URL.
        *   `FAILED`: Gặp lỗi trong quá trình xử lý.

2.  **Cập nhật Domain Entity:**
    *   Chỉnh sửa class `Share` trong `domain/entities/share.ts` để sử dụng `ShareStatus` thay vì kiểu `string` thuần túy.
    *   Cập nhật các phương thức `create`,`completeUpload` và `failUpload` để gán giá trị từ enum.

3.  **Cập nhật Cơ sở dữ liệu (ORM):**
    *   Chỉnh sửa `ShareEntity` trong `infrastructure/database/entities/share.entity.ts` để sử dụng kiểu dữ liệu `enum` của TypeORM. Điều này giúp kiểm soát dữ liệu chặt chẽ hơn ở mức database.

4.  **Cập nhật API & Logic:**
    *   Bổ sung trường `status` vào kết quả trả về của `GenerateLinkShareCommandHandler` và `GetAllShareQueryHandler` để client có thể theo dõi tiến độ export của các link chia sẻ.

Việc sử dụng Enum giúp tránh các lỗi do sai lệch chuỗi ký tự (typo) và làm cho code rõ ràng, dễ bảo trì hơn.
