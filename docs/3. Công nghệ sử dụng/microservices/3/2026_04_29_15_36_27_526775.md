

## 📝 Lý do cần dùng Factory

### **1. Tách biệt Application Layer khỏi Domain complexity**
```typescript
// ❌ Application Layer phải biết về Money, Value Objects
const price = new Money(command.price);
const plan = Plan.create(name, duration, price, isActive);

// ✅ Application Layer chỉ làm việc với primitive types
const plan = PlanFactory.create(name, duration, price, isActive);
```

### **2. Đơn giản hóa việc tạo Entity**
```typescript
// ❌ Phức tạp - phải tạo nhiều Value Objects
const userId = new UserId(command.userId);
const planId = new PlanId(command.planId);
const subscriptionId = new SubscriptionId(subscription.subscriptionId.value);
const baseAmount = new Money(plan.price.amount);
// ... 10 dòng code nữa

const transaction = Transaction.create(userId, subscriptionId, ...);

// ✅ Đơn giản - Factory xử lý hết
const transaction = TransactionFactory.create(
  command.userId,
  subscriptionId,
  planId,
  baseAmount,
  // ...
);
```

### **3. Tái sử dụng logic khởi tạo**
Nếu có nhiều nơi cần tạo Transaction, không cần lặp lại code tạo Value Objects.
