Mình đã chỉnh sửa lại câu lệnh SQL trong file `step_rag_embedding.py` để mapping đúng vào sơ đồ database mới của bạn. Cụ thể:

2. **Cập nhật bí danh (Alias) cho cột:**

   - `d.eff_from` đổi tên thành `effective_date`.

   - `d.doc_num` đổi tên thành `document_number`.
