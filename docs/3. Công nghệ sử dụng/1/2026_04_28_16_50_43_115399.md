Hai trường dữ liệu này hoàn toàn khác nhau về mục đích sử dụng và nội dung bên trong bạn nhé:

1. **`document_related_files` (từ `documentRelatedList`)**:
   Đây là danh sách các **File tài liệu đính kèm** của văn bản.
   - Nó chứa thông tin về các tệp vật lý như file PDF (bản scan có chữ ký), file Word `.docx` (bản mềm để tải về), hoặc file `.html` (nội dung toàn văn).
   - Ví dụ: `1628_QD_QD_2026.pdf` hay `...content.html`.

2. **`document_references` (từ `references` trong API Detail)**:
   Đây là danh sách các **Văn bản pháp lý có liên quan** đến văn bản hiện tại.
   - Khi một văn bản mới ban hành, nó thường lấy một số Luật/Nghị định khác làm *căn cứ pháp lý*, hoặc nó *sửa đổi, bổ sung, bãi bỏ* các văn bản cũ. Toàn bộ mối quan hệ này (lược đồ mạng lưới văn bản) sẽ nằm ở đây.
   - Nó chứa thông tin như: Mã số ID của văn bản đích (`targetDocument`), số hiệu văn bản (`docNum` - ví dụ: *Luật Tổ chức chính quyền địa phương số 72/2025/QH15*), tiêu đề văn bản, và loại liên kết (`referenceType` - ví dụ loại 3 có thể là "Căn cứ pháp lý", loại 1 là "Thay thế").

**Tóm lại:**
- Bạn muốn tìm file PDF/Word để tải về tải liệu -> Dùng bảng **`document_related_files`**.
- Bạn muốn vẽ sơ đồ vòng đời, tra cứu xem văn bản này thay thế cho văn bản nào, căn cứ vào Luật nào -> Dùng bảng **`document_references`**.
