Cấu trúc dự án của bạn tuân thủ rất chặt chẽ theo mô hình Clean Architecture kết hợp CQRS. Thay vì chỉ tô màu cho 3 file gốc (`.api.ts`,`.application.ts`,`.infrastructure.ts`), chúng ta có thể phân nhóm toàn bộ các đuôi file `.ts` theo từng Layer (Tầng) và gán cho mỗi tầng một màu sắc riêng biệt để biểu đồ trực quan nhất.

Dưới đây là cách phân loại màu sắc đề xuất:

* **Tầng API (Màu Tím/Hồng - plum):** Chịu trách nhiệm giao tiếp ngoài (`.controller.ts`,`request/response dto.ts`,`.api.ts`).
* **Tầng Application (Màu Xanh Dương nhạt - lightblue):** Chứa logic điều phối, use-cases (`.command.ts`,`.query.ts`,`-handler.ts`,`.processor.ts`,`.application.ts`).
* **Cổng Giao Tiếp / Ports (Màu Vàng - gold):** Interfaces định nghĩa hợp đồng cho Infrastructure (`.port.ts`). Đặt màu nổi bật để dễ thấy sự đảo ngược phụ thuộc (Dependency Inversion).
* **Tầng Domain (Màu Xanh Lá - palegreen):** Trái tim của hệ thống, chứa business rules (toàn bộ file nằm trong thư mục `/domain/`).
* **Tầng Infrastructure (Màu Cam nhạt - peachpuff):** Tương tác với DB, external API, Message Broker (`.cron.ts`,`orm.entity.ts`,`.mapper.ts`,`.orm-repository.ts`,`.adapter.ts`,`.service.ts`,`.infrastructure.ts`).

### Cấu hình Dependency Cruiser Theme

Bạn hãy chèn đoạn cấu hình `options` này vào file `.dependency-cruiser.js` của bạn:

```javascript
module.exports = {
  // ... mảng forbidden rules của bạn ở đây ...

  options: {
    reporterOptions: {
      dot: {
        theme: {
          modules: [
            // 1. Ports (Nổi bật nhất - Vàng)
            {
              criteria: { source: '\\.port\\.ts$' },
              attributes: { fillcolor: 'gold', style: 'filled', shape: 'cds' }
            },
            // 2. Tầng API (Tím/Hồng)
            {
              criteria: { source: '\\.(controller|dto|api)\\.ts$' },
              attributes: { fillcolor: 'plum', style: 'filled' }
            },
            // 3. Tầng Application (Xanh Dương)
            {
              criteria: { source: '\\.(command|command-handler|query|query-handler|event-handler|processor|application)\\.ts$' },
              attributes: { fillcolor: 'lightblue', style: 'filled' }
            },
            // 4. Tầng Infrastructure (Cam nhạt)
            {
              criteria: { source: '\\.(cron|entity|mapper|orm-repository|adapter|service|infrastructure)\\.ts$' },
              attributes: { fillcolor: 'peachpuff', style: 'filled' }
            },
            // 5. Tầng Domain (Xanh Lá)
            // Bắt tất cả file .ts nằm trong thư mục domain
            {
              criteria: { source: '/domain/.*\\.ts$' },
              attributes: { fillcolor: 'palegreen', style: 'filled', shape: 'box' }
            },
            // 6. Các file cấu hình/constants (Xám nhạt)
            {
              criteria: { source: '\\.(constant|module)\\.ts$' },
              attributes: { fillcolor: 'lightgrey', style: 'filled', shape: 'folder' }
            }
          ],
          // Tùy chỉnh màu sắc đường mũi tên (dependencies)
          dependencies: [
            {
              criteria: { "resolved": "^src/modules/[^/]+/domain" },
              attributes: { color: 'darkgreen' } // Đường trỏ vào Domain sẽ có màu xanh đậm
            }
          ]
        }
      }
    }
  }
};
```

### Các hình khối (Shape) được thêm vào để dễ nhìn hơn:
* **`.port.ts`**: Dùng shape `cds` (hình thẻ ghi chú có viền cắt) để biểu diễn interface.
* **Domain**: Dùng shape `box` (hình chữ nhật) để thể hiện sự vững chắc của core logic.
* **`.module.ts` / `.constant.ts`**: Dùng shape `folder`.
* Các file còn lại sử dụng hình oval mặc định.
