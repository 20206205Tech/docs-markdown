# Sơ đồ Infrastructure as Code (IaC) sử dụng terraform






![alt text](images/infrastructure-as-code-IaC-terraform.excalidraw.png)




Terraform là công cụ mã nguồn mở của HashiCorp, nổi bật trong lĩnh vực Hạ tầng dạng mã (IaC - Infrastructure as Code), giúp định nghĩa và quản lý hạ tầng (cloud, network, database) thông qua tệp cấu hình thay vì thao tác thủ công.Các đặc điểm nổi bật



Chào các bạn tới với series về Terraform. Ở bài đầu tiên chúng ta sẽ tìm hiểu IaC (Infrastructure as Code) là gì, Terraform là gì và tại sao ta cần nó.
