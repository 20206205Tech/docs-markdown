Tôi đang sử dụng Kong API Gateway cho hệ thống microservice.

Nhưng lại deploy image docker trên render free bị tắt sau 15 phút.

Địa chỉ https://api.20206205.tech

Giao diện NextJS gọi Kong API Gateway: BaseApiUrl = https://api.20206205.tech/api + môi trường ('/dev' hoặc '/prod')
